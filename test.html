🔹 C++ là gì?

C++ là một ngôn ngữ lập trình bậc cao, được phát triển bởi Bjarne Stroustrup vào năm 1985 tại Bell Labs. Đây là phiên bản mở rộng của ngôn ngữ C với nhiều tính năng hiện đại như Lập trình hướng đối tượng (OOP), Lập trình tổng quát (Template) và Quản lý bộ nhớ thông minh.

🔹 Lịch sử phát triển

1985
Phiên bản đầu tiên "C with Classes" - Bjarne Stroustrup giới thiệu C++
1989
C++ 2.0 với đa kế thừa (Multiple Inheritance)
1990
C++ 3.0 với template và exception handling
1998
C++98 - Chuẩn hóa lần đầu bởi ISO
2003
C++03 - Bản sửa lỗi của C++98
2011
C++11 - Bước đột phá với auto, lambda, move semantics, smart pointers
2014
C++14 - Cải tiến nhỏ từ C++11
2017
C++17 - filesystem, optional, variant, structured bindings
2020
C++20 - concepts, ranges, coroutines, modules
2023
C++23 - C++ đang tiếp tục phát triển mạnh mẽ

🔹 Tại sao nên học C++?

🚀 Hiệu suất vượt trội

C++ là ngôn ngữ nhanh nhất trong số các ngôn ngữ bậc cao. Nó cho phép bạn kiểm soát bộ nhớ trực tiếp, tối ưu hóa code để chạy với tốc độ gần bằng Assembly.

🎮 Vua của ngành Game

Hầu hết các engine game lớn đều được viết bằng C++: Unreal Engine, CryEngine, Unity (core).

💰 Lương cao, nhu cầu lớn

Lương C++ thuộc top đầu. Mức lương trung bình tại Việt Nam: 20-50 triệu/tháng.

🤖 AI & Machine Learning

TensorFlow, PyTorch, Caffe đều có core viết bằng C++ để tối ưu hiệu năng.

🖥️ Hệ điều hành & Nhúng

Windows, Linux, macOS kernel đều viết bằng C/C++. IoT, vi điều khiển dùng C++.

🧠 Nền tảng vững chắc

Học C++ giúp bạn hiểu sâu về máy tính. Khi đã giỏi C++, dễ học Java, Python, C#.

🔰 Cấu trúc chương trình C++

// Chương trình Hello World
#include <iostream>

using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
  • #include - Thêm thư viện
  • using namespace std - Sử dụng không gian tên std
  • int main() - Hàm chính
  • cout - In ra màn hình
  • return 0 - Kết thúc chương trình

✨ Lớp và Đối tượng (OOP)

class Student {
private:
    string name;
    int age;
    float gpa;

public:
    Student(string n, int a, float g) {
        name = n;
        age = a;
        gpa = g;
    }

    void display() {
        cout << "Tên: " << name << endl;
        cout << "Tuổi: " << age << endl;
        cout << "GPA: " << gpa << endl;
    }
};

Student s1("Nguyễn Văn A", 20, 3.8);
s1.display();

✨ Kế thừa (Inheritance)

class Animal {
public:
    void eat() {
        cout << "Eating..." << endl;
    }
};

class Dog : public Animal {
public:
    void bark() {
        cout << "Gâu gâu!" << endl;
    }
};

Dog myDog;
myDog.eat();
myDog.bark();

✨ STL - Vector

#include <vector>
vector<int> numbers = {5, 2, 8, 1, 9};
numbers.push_back(7);
sort(numbers.begin(), numbers.end());

for (int x : numbers) {
    cout << x << " ";
}
// Output: 1 2 5 7 8 9
